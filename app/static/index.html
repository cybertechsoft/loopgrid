PORTABLE EVIDENCE
Trust that travels with the record.
Export evidence that can be checked without access to the LoopGrid service.

          

            
01 / VERIFY
Offline verification
A recipient verifies canonical event hashes, the workspace chain and the configured digital signature using only the exported public key.
python loopgrid_verify.py evidence.zip

            
02 / PRIVACY
Three capture modes
Full encrypts raw payloads in a separate disclosure vault while the signed ledger keeps a commitment. Redacted commits sensitive fields by hash. Proof-only keeps only a payload commitment.

            
03 / CONTINUITY
Proof-only witnesses
Interleaved records are bridged with cryptographic witnesses, without disclosing other decision payloads.

            
04 / CHECKPOINT
Checkpoint attestation
Sign the current workspace chain head. If a real RFC 3161 TSA is configured, LoopGrid stores the timestamp response with the checkpoint and evidence bundle.
