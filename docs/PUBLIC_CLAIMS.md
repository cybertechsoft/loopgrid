# Public claim ledger — LoopGrid v0.8

Use this file when editing GitHub, PyPI, npm, the landing page, outreach or diligence material.

## Preferred category

**The evidence plane for AI agents.**

## Preferred product description

LoopGrid is verifiable evidence infrastructure for consequential AI and agent decisions. It captures agent identity, delegated authority, model/context, policy, human oversight, action and observed outcome, then seals that history as signed, tamper-evident evidence that can be exported and verified independently.

## Safe phrases

- signed evidence
- tamper-evident evidence
- workspace-scoped hash chain
- portable evidence bundle
- independent / offline verification
- signer pinning
- deterministic policy provenance
- human review / human adjudication
- controlled design-partner technical evaluation
- PostgreSQL-backed deployment path

## Do not use

- immutable / cryptographically immutable
- human correction is ground truth
- EU AI Act compliant / compliance guaranteed
- SOC 2 compliant, HIPAA compliant or similar certification language
- production ready / enterprise production ready
- hardware-backed signing unless a live KMS deployment was actually validated
- TSA signer trust unless CA-chain validation was actually exercised

## One-line differentiation

**Agent runtimes execute. Observability explains. Control planes govern. LoopGrid proves what happened.**
